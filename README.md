# python-scripts

A collection of standalone Python scripts — algorithm exercises, small
utilities, and other one-off programs.

## Scripts

- [`postfix_to_infix.py`](postfix_to_infix.py) — converts a postfix
  (Reverse Polish Notation) expression into an infix expression using
  the minimum number of parentheses required to preserve evaluation
  order, based on operator precedence and left-associativity. Returns
  `"invalid"` (or `"format invalid"`) if the input can't be parsed as
  a valid postfix expression.
